# Code of Conduct

This project follows the **Contributor Covenant version 2.1**.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Concerns can be reported to the maintainers via:

- Email: conduct@maecly.com
- Or by opening a private GitHub Security Advisory on this repository.

Reports are reviewed within 5 business days. Reporter identity is kept confidential.

## Scope

This applies to all project spaces (repository, issues, pull requests, discussions, and any official channels) and to public spaces when an individual is representing the project.

## Enforcement

Maintainers will follow the **Contributor Covenant Enforcement Ladder** (warning → temporary ban → permanent ban) as appropriate to the severity of the issue.
