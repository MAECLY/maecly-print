Summary: Free batch file printing for Windows and macOS. Select 5, 50 or 500 files and print them as one job with one set of settings: PDF and images directly, Office, OpenDocument, HTML and Markdown through LibreOffice, a browser or Pandoc installed separately. A queue saved on disk with automatic retries, named print profiles, a command line with JSON output, and a Finder Services entry on macOS. No account and no telemetry.
